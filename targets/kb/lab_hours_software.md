# Computer Lab Hours and Software

The campus has three open-access computer labs. All run a standard managed
Windows 11 image; a small Linux cluster is available in the Engineering lab.

## Opening hours

- Main Library lab (room L-120): open 24 hours, 7 days a week, with card
  access required between 22:00 and 07:00.
- Science lab (room S-204): Mon-Fri 08:00-20:00, closed weekends.
- Engineering lab (room E-310), including the Linux cluster: Mon-Sat
  09:00-21:00.

## Installed software

Every managed machine includes Microsoft Office, the Chrome and Firefox
browsers, Python 3.12, R, MATLAB, and the campus VPN client. Specialist
software (for example ANSYS, SPSS and Adobe Creative Cloud) is available only
on tagged machines; check the sign at each bay.

## Requesting extra software

Teaching staff can request additional software for a lab by filing a ticket
at https://it.example.edu/software at least 10 working days before it is
needed. Students cannot install software themselves; the machines reset to the
standard image at every restart.

Printing is available in all labs. Each student has a termly print quota of
500 black-and-white pages; colour pages count as 3 pages each.
